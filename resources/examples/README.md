## Running Examples

- **Web / Desktop App:** Open via **File > Open Example** or load any `.ipes` file directly.
- **Automation & Headless Simulation:** See the [Scripting & Automation](../../docs/tutorials/scripting/index.md), [REST API](../../docs/api/rest-api.md), and [`geckopy` Python SDK](../../docs/tutorials/scripting/python.md) guides.
